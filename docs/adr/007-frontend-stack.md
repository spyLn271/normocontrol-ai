Статус: принято (2026-10-25)

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Next.js (App Router)** | SSG страниц на ru/kk, Route Handlers (прокси к API в том же образе), standalone-сборка | тяжелее Vite |
| React + Vite | проще, быстрее сборка | нужен отдельный сервер для прокси/SSR, i18n-роутинг вручную |

## Решение

* Next.js 16.4.2 + React 19, TypeScript strict, Tailwind CSS v4 с токенами стиля Refero (Dub) —
  `web/src/styles/tokens.css`; компоненты в духе shadcn/ui (Radix), без «магических» цветов.
* Графики — **Bklit UI** (`@bklit/gauge-chart`, `@bklit/ring-chart`): это shadcn-registry, а не
  npm-пакет, ставится `shadcn add`; файлы в `src/components/charts/` не правим, чтобы обновлять.
  Рендер только на клиенте (SVG-пути Node и браузера отличаются в последних знаках → hydration).
* Данные — TanStack Query (опрос статуса проверки раз в секунду), ответы API валидируются zod.
* i18n — next-intl, локали `/ru/…` и `/kk/…`, `/` перенаправляет по cookie/Accept-Language.
* Прокси `/api/*` — потоковый Route Handler: `API_URL` читается при запуске (один образ на все
  окружения), загрузка не буферизуется, недоступный бэкенд → 502 в формате ошибок API.
* Режим моков `NEXT_PUBLIC_API_MOCK=1` и демо-отчёт `/ru/checks/demo` — разработка без бэкенда.

## Отступления от FRONTEND.md

* Satoshi нет в Google Fonts — крупные заголовки Inter 600.
* Цвета текста бейджей серьёзности затемнены (#b91c1c, #9a3412, #1d4ed8, #166534): исходные пары
  не проходят WCAG AA (контраст 3.0–4.2); исходные цвета оставлены для графиков.
* `next`, `eslint-config-next` 16.4.2 и `zod` 4.6.7 — новее двухнедельного окна: в более ранних
  версиях известные уязвимости (RCE в Next ≤ 16.4.0, исчерпание памяти в zod < 4.6.6).
