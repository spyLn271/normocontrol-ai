# 004. Шорт-лист моделей

Статус: принято (2026-10-25); финальный выбор — по бенчмарку (задача 3.7, ADR 011)

| Роль | По умолчанию | Для разработки / слабого ПК | Сравнить |
|---|---|---|---|
| LLM | `qwen3:8b` | `qwen3:4b` | `qwen3:14b`, `gemma3:12b`, ISSAI KazLLM / Sherkala (казахский) |
| Эмбеддинги | `bge-m3` | `bge-m3` | `qwen3-embedding:0.6b`, `multilingual-e5-large` (с префиксами `query:`/`passage:` в конфиге) |
| Reranker | выключен | — | `BAAI/bge-reranker-v2-m3` (extra `rerank`) |

## Эксперимент (2026-10-25, CPU)

**Эмбеддинги `bge-m3`** на реальных документах (Правила № 236, МИ 049-2026; 54 вопроса,
`tests/rag/questions.yaml`): **Hit@5 = 0.981, MRR = 0.894, Hit@1 = 0.833**
(docs/benchmarks/2026-10-25-rag.md).

**LLM `qwen3:4b`** — проверка 8 записей литературы (2 намеренно испорчены, 6 корректных,
5 из них — образцы из Приложения И МИ 049-2026), подробности — docs/benchmarks/2026-10-25-llm.md:

| Защита | Найдено верных | Ложных | Отброшено защитой |
|---|---:|---:|---:|
| только paragraph_id / rule_ref / цитата | 2 из 2 | 6 | 0 |
| + «исправление ничего не меняет» + «совпадает с образцом» + промпт v2 | 2 из 2 | 1 | 5 |

Вывод: маленькая модель находит реальные ошибки, но без дополнительных защит даёт много
ложных — защиты обязательны, а модель по умолчанию — не меньше `qwen3:8b`.
Режим thinking на CPU непрактичен (> 4 800 токенов рассуждений на запрос, десятки минут на
документ) — по умолчанию выключен, сравнение — только на GPU.

## Последствия

Модели задаются только конфигом (`llm.model`, `embeddings.model`). Смена модели эмбеддингов
требует переиндексации (`normocontrol rag index-registry`).
