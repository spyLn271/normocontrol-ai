# Фронтенд: дизайн и компоненты

## Источники дизайна (обязательно использовать)

| Ресурс | Что берём | Ссылка |
|---|---|---|
| **Refero Styles — дизайн-система Dub** | цвета, шрифты, отступы, радиусы, тени, правила компонентов. На странице есть вкладки **DESIGN.md**, **Tailwind v4**, **CSS Variables**, **Design Tokens** — всё можно скопировать готовым | https://styles.refero.design/style/b0d80806-b724-4ed1-a1d1-074edd3c9bc9 |
| **Bklit UI** | готовые React-компоненты графиков для отчёта: Gauge (балл соответствия), Ring/Pie (ошибки по категориям), Bar (ошибки по разделам), Heatmap (ошибки по страницам). Есть документация, рецепты, блоки и Skills для ИИ-ассистентов | https://bklit.com/ (документация: раздел Docs) |

> Используем **стиль**, а не бренд: логотип, название и иллюстрации Dub не копируем. У нас свой логотип и название.

## Как подключить

1. Открыть страницу Refero → вкладка **DESIGN.md** → **Copy** → сохранить в `web/design/DESIGN.md`.
   Этот файл — главный источник правды по дизайну, его же давать ИИ-ассистенту при генерации компонентов.
2. Вкладка **Tailwind v4** (или **CSS Variables**) → скопировать в `web/src/styles/tokens.css`.
3. Bklit UI — установить по инструкции из их Docs (раздел Get started) и подключить их Skills к ИИ-ассистенту, если пользуешься.
4. Никаких «магических» цветов и размеров в компонентах — только токены.

## Ключевые токены (кратко, полный список — в DESIGN.md)

| Что | Значение |
|---|---|
| Фон | `#ffffff`, альтернативный фон `#f5f5f5` |
| Граница (главный элемент стиля) | `1px solid #e5e5e5` — контейнеры отделяются рамками, а не тенями |
| Основной текст | `#171717`, приглушённый `#737373` |
| Акцент | `#2563eb` — ссылки, активные состояния, ключевые цифры |
| Главная кнопка | тёмная заливка (`#0a0a0a`), одна на экран |
| Шрифты | Inter — весь интерфейс; Satoshi 500 — только крупные заголовки 36–48px; Geist Mono — код и технические значения |
| Радиусы | теги/бейджи `9999px`, кнопки `8px`, карточки `12px`, большие карточки `16px`, поля ввода `6px` |
| Отступы | шаг 4px, плотная сетка, gap 8px, между секциями 64px, max-width 1200px |

## Цвета статусов для отчёта

Стиль Dub почти монохромный, поэтому цвета серьёзности ошибок используем **только в бейджах и графиках**, не на больших площадях:

| Серьёзность | Цвет текста | Фон бейджа |
|---|---|---|
| error | красный (подобрать из палитры Tailwind `red-600`) | светлый красный |
| warning | `#ea580c` (Tangerine) | светлый оранжевый |
| info | `#2563eb` | `#dbeaff` |
| ok / исправлено | `#16a34a` | `#dcfce7` |

Зафиксировать окончательные значения в `tokens.css` и проверить контраст (WCAG AA).

## Экраны MVP

1. **Главная / загрузка** — заголовок, drag-and-drop файла `.docx`, выбор профиля (вуз / тип документа), кнопка «Проверить».
2. **Проверка идёт** — прогресс по шагам: чтение файла → правила оформления → структура → ИИ-проверки.
3. **Отчёт**
   - сверху: Gauge с баллом соответствия (Bklit) + число ошибок по серьёзности (бейджи);
   - Ring-диаграмма: ошибки по категориям (поля, шрифты, структура, литература…);
   - список ошибок карточками: что не так → где (страница/абзац, цитата) → как исправить → основание (пункт стандарта, раскрывается);
   - фильтры: серьёзность, категория;
   - кнопки: «Скачать отчёт PDF», «Скачать .docx с комментариями».
4. **Профили** — список доступных профилей и их источников.

## Задачи фронтенда

См. этап 4 в [TASKS.md](TASKS.md). Порядок:
1. скопировать DESIGN.md и токены, собрать страницу-витрину токенов (`/design`) — кнопки, бейджи, карточки, поля ввода;
2. экран загрузки;
3. экран отчёта на **моковых данных** (JSON из `tests/fixtures/`), не дожидаясь готового API;
4. подключить реальный API;
5. адаптив под телефон (ширина 375px) и тёмная тема (по желанию).
